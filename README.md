# 静园苗圃

一个网页解谜游戏。朋友林小满失踪三天，最后只留下一个诡异的广告链接。你要在一台模拟电脑上搜索、翻博客和论坛、查看网页源代码，把她找回来。

**在线游玩：** https://yiyayoh.github.io/jymp-game/

## 玩法

- 在游戏里的地址栏输入网址，或者用“寻度”搜索关键词
- 全选页面文字（Ctrl+A），可能会看到藏起来的字
- 点地址栏右边的 `</>` 查看网页源代码
- 右侧的调查笔记会自动记录线索，卡住了可以点“给我一点提示”

## 章节

1. **静园**：找到失踪的林小满。
2. **第三排**：帮五个女孩完成她们没做完的事。
3. **三点十二分**：找到逃走的陈默，让他亲口说出真相。

共有三个结局（坏结局、普通结局、真结局）。第一次通关大约需要 2～3 小时，进度自动保存在浏览器本地。

## 背景音乐

每类页面都有不同的背景音乐和音效，全部由浏览器实时合成，没有音频文件。点“开始调查”后开始播放，右侧面板可以随时关闭。建议戴耳机。

## 本地运行

下载 `index.html`，双击用浏览器打开即可，无需安装。
